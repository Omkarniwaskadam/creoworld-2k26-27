# CREO WORLD 2K26 — Interactive Event Website

## What was added
- Animated CREO hero/orb visual with CSS-only motion
- Responsive event cards with visual icons
- Degree / Polytechnic / Saved filters
- Search and sorting
- Card / Compact views
- Save/star events for a personal shortlist
- Random Challenge / Surprise Me picker
- Interactive 5-step participant checklist with progress bar
- Event constellation visual
- Rich event modal containing participation guide, rules, contacts and registration
- Source transparency notes for missing or inconsistent source information
- Mobile responsive layout and reduced-motion support

## Run
Open this folder in VS Code and use **Live Server** on `index.html`.

Do not open `index.html` with a plain `file://` URL if the browser blocks loading `events.json`.

## Files
- `index.html` — page structure
- `style.css` — design, visuals and responsive layout
- `events.js` — interactions
- `events.json` — event data extracted from the supplied documents
