SOURCE & TRANSPARENCY

Built from your CREO WORLD files

This interactive website uses the uploaded event-plan and detailed event/rules documents. Missing information is not invented. Where source files use different names for an event, the difference is shown in the event note.

⚠ SOURCE NOTE

For example, the Degree source contains “RoboChrono Challenge” rules while the event plan names the event “RoboFootball League”. The website preserves this distinction for verification.
